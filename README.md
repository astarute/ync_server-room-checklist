# 서버실 점검 체크리스트 (PWA)

NFC 태그로 "서버실에 실제로 갔다"는 걸 확인하고, 온도·습도·장비 상태를 기록하는
학교 내부용 웹앱입니다. 구글플레이에 올리지 않고 GitHub Pages로만 내부 배포합니다.

## 이 앱이 하는 일

1. 처음 실행 시 이름을 한 번 등록합니다 (기기에 저장, 자동으로 기억됨).
2. "NFC 태그 스캔" 버튼을 누르고 서버실 입구에 붙여둔 NFC 태그에 폰을 가까이 대면
   태그 고유번호 + 이름 + 시간이 자동으로 확인됩니다.
3. 온도(필수)·습도·장비 상태 체크리스트·이상 메모·사진을 입력하고 제출합니다.
4. 제출 기록은 Google 시트에 쌓이고, 앱 안에서 최근 기록을 바로 볼 수 있습니다.
5. 네트워크가 안 되면 기기에 임시 저장했다가, 온라인이 되면 자동으로 다시 보냅니다.

> Web NFC(브라우저 NFC 스캔)는 **안드로이드 기기의 크롬 브라우저에서만** 동작합니다.
> 아이폰은 Safari가 이 기능을 지원하지 않아 "수동으로 확인" 버튼으로 대체해야 합니다.

## 1단계 — GitHub 저장소 만들고 배포하기 (사이트 자체)

1. GitHub에 새 저장소를 만듭니다. (예: `server-room-checklist`, 학교 조직 계정이 있다면
   조직 소유로 만들고 접근 권한을 관계자로 제한하면 더 안전합니다.)
2. 이 폴더 안의 모든 파일(`index.html`, `style.css`, `app.js`, `manifest.json`, `sw.js`,
   `icons/` 폴더, `apps-script.gs`, 이 `README.md`)을 저장소 루트에 업로드하고 커밋합니다.
3. 저장소 **Settings → Pages** 로 이동합니다.
4. **Source**를 `Deploy from a branch`로, 브랜치는 `main` (또는 기본 브랜치), 폴더는 `/root`
   로 선택하고 저장합니다.
5. 잠시 후 `https://<계정 또는 조직>.github.io/<저장소이름>/` 주소가 생성됩니다.
   이 주소가 앱 주소입니다. 관계자들에게 이 링크를 전달하면 됩니다.
6. 저장소를 **Private**으로 두고 싶다면 GitHub Pages는 공개 저장소가 기본이라 별도 플랜이
   필요할 수 있습니다. 완전한 내부 전용을 원하면 조직의 GitHub Enterprise/Team 플랜을
   쓰거나, 사내망에서만 접근 가능한 다른 정적 호스팅(사내 웹서버 등)을 고려하세요.
   일반적인 학과 규모라면 "링크를 아는 사람만 접속" 수준으로도 충분한 경우가 많습니다.

### 모바일에 설치하기 (앱처럼 쓰기)

- 안드로이드 크롬: 주소 열기 → 우측 상단 메뉴(⋮) → "홈 화면에 추가" → 설치.
- 아이폰 Safari: 주소 열기 → 공유 버튼 → "홈 화면에 추가".

## 2단계 — 기록 저장용 Google 시트 + Apps Script 배포

기록(누가/언제/몇 도/이상 유무)을 저장할 곳으로 Google 시트를 씁니다. 별도 서버 비용이
들지 않고, 학교 계정이면 관리자들이 시트를 바로 열어볼 수 있어 편합니다.

1. Google Drive에서 새 **Google 시트**를 만듭니다. (이름은 자유롭게, 예: `서버실점검기록`)
2. 시트 주소창의 URL에서 ID를 복사합니다.
   `https://docs.google.com/spreadsheets/d/`**`이 부분이 ID`**`/edit`
3. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다.
4. 기본 `Code.gs` 내용을 지우고, 이 프로젝트의 `apps-script.gs` 파일 내용을 전부 붙여넣습니다.
5. 코드 상단의 `SHEET_ID = '여기에_구글시트_ID를_붙여넣으세요'` 부분을 2번에서 복사한
   ID로 바꿉니다.
6. (권장) `SHARED_SECRET = ''` 부분을 임의의 문자열로 바꿔두면, 이 값을 모르는 사람은
   기록을 조회/제출할 수 없어 더 안전합니다. 예: `SHARED_SECRET = 'univ-2026-secret'`
   - 이 경우 PWA `app.js`의 `sendRecord`/`loadHistory` 요청에 `secret` 값을 같이
     보내도록 코드를 살짝 수정해야 합니다 (필요하면 요청해주세요, 추가해드릴게요).
   - 비워두면 URL만 아는 사람은 누구나 접근 가능하니, URL을 외부에 공유하지 않는 것만으로
     내부용으로는 충분한 경우가 많습니다.
7. 상단 **배포 → 새 배포**를 클릭합니다.
   - 유형 선택(⚙️ 아이콘) → **웹 앱**
   - 설명: 아무거나 (예: `v1`)
   - 실행 계정: **나**
   - 액세스 권한: **전체(Anyone)** (학교 Workspace 조직 계정이 있다면 "조직 내 전체"도 가능)
   - **배포** 클릭 → 처음엔 권한 승인 화면이 뜨는데, 본인 계정으로 승인해줍니다
     (Google이 "확인되지 않은 앱" 경고를 띄우면 고급 → 이동을 눌러 진행하면 됩니다.
     내가 만든 스크립트라서 안전합니다).
8. 배포가 끝나면 `https://script.google.com/macros/s/xxxxxxxx/exec` 형태의
   **웹앱 URL**이 나옵니다. 이 주소를 복사해둡니다.
9. 코드를 나중에 수정하면, 다시 배포하지 않으면 반영되지 않습니다.
   **배포 → 배포 관리 → 연필(수정) 아이콘 → 새 버전** 으로 다시 배포해야 합니다.

## 3단계 — 앱에 저장 주소 연결하기

1. GitHub Pages로 올린 앱 주소를 엽니다.
2. 우측 상단 톱니바퀴(⚙️ 설정) 아이콘을 누릅니다.
3. "서버 저장 주소" 칸에 2단계에서 복사한 Apps Script 웹앱 URL을 붙여넣고 저장합니다.
4. 이제 제출한 기록이 Google 시트에 쌓이고, 앱 홈 화면에서 최근 기록도 보입니다.

> 이 설정은 기기마다 한 번씩 해줘야 합니다(브라우저 저장소에 기기별로 저장되는 방식이라서).
> 관계자가 여러 명이면 각자 기기에서 한 번씩만 주소를 입력하면 됩니다.

## 4단계 — 서버실 NFC 태그 준비

특별한 프로그램으로 태그에 뭔가를 "쓸" 필요가 없습니다. 빈 NFC 태그(스티커형, 다이소/알리
익스프레스 등에서 저렴하게 구매 가능)를 서버실 입구에 붙여두기만 하면 됩니다. 태그마다
고유한 일련번호가 있어서, 앱이 그 번호를 자동으로 인식합니다.

1. 서버실 입구(또는 랙 앞)에 NFC 태그를 붙입니다.
2. 안드로이드 폰의 크롬으로 앱을 열고 "NFC 태그 스캔 시작"을 누른 뒤 그 태그에 폰을 댑니다.
3. 처음 인식되는 태그는 "이 위치의 이름을 입력해주세요"라고 물어봅니다.
   예: `본관 서버실 입구`, `제2서버실 랙A` 등 원하는 이름을 입력하면 등록됩니다.
4. 이후에는 같은 태그를 스캔할 때마다 자동으로 그 위치로 인식되어 체크리스트로 바로
   넘어갑니다.
5. 서버실이 여러 곳이면 태그를 여러 개 붙이고 각각 다른 이름으로 등록하면 됩니다.
   단, 이 등록 정보는 기기(브라우저)별로 저장되므로, 각 관리자 폰에서 한 번씩 스캔해서
   등록해줘야 합니다. (인원이 많다면 다음 개선 아이디어 참고)

## 알아두면 좋은 점 / 한계

- **보안**: 이 구성은 "내부용 소규모 도구"에 맞춘 가벼운 방식입니다. 회사/학교 공식
  보안 정책이 있다면 Apps Script의 `SHARED_SECRET`을 꼭 설정하고, GitHub 저장소도 접근
  권한을 제한하세요.
- **사람 확인의 한계**: NFC 태그는 "그 위치에 있었다"는 것만 증명하고, 누가 눌렀는지는
  앱에 등록된 이름을 그대로 믿는 방식입니다(별도 로그인 비밀번호 없음). 더 엄격한 신원
  확인이 필요하면 학교 SSO/Google 로그인 연동을 추가할 수 있습니다 — 필요하면 말씀해주세요.
- **iOS 사용자**: Web NFC를 지원하지 않으므로 "수동으로 확인" 버튼을 쓰게 되고, 이 경우
  위치 증빙이 약해집니다(선택적으로 GPS 좌표를 같이 기록합니다).
- **사진 저장**: 제출 시 첨부한 사진은 Google Drive의 `서버실점검_사진첨부` 폴더에
  자동 저장되고, 시트에는 그 링크만 남습니다.

## 파일 구성

```
index.html         메인 화면(HTML)
style.css           디자인
app.js              동작 로직(NFC 스캔, 저장, 제출, 오프라인 큐)
manifest.json        PWA 설치 설정
sw.js               오프라인 캐싱용 서비스워커
icons/              앱 아이콘
apps-script.gs       구글 시트에 붙이는 백엔드 코드
```
